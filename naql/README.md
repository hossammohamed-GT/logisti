# naql — الرابط الموحّد للبطاقات والتراخيص

الرابط:

```
http://localhost/logisti/naql/validate-driver-card?token=XXXX
```

التوكن هو اللي يحدد الصفحة اللي تُعرض:

| النوع (Role)              | التوكن                                 | مصدر البيانات              |
|---------------------------|----------------------------------------|----------------------------|
| بطاقة سائق (Driver Card)  | أي توكن موجود في جدول `driver_cards`   | قاعدة البيانات             |
| بطاقة تشغيل (Operation)   | `eddc5956-9eb8-49b7-ac12-380247e30099` | ثابتة في `static-data.php` |
| ترخيص (License)           | `dcd63444-e888-454a-8c47-bbdbfdde04cd` | ثابتة في `static-data.php` |

أي توكن غير معروف → نفس السلوك القديم (`window.close()`).

## الملفات

- `validate-driver-card.php` — الراوتر: يحدد النوع من التوكن ثم يستدعي القالب.
- `static-data.php` — البيانات الثابتة (أضف توكن جديد هنا بنفس الشكل).
- `views/driver-card.php` — محتوى بطاقة السائق (نفس المحتوى القديم بالحرف).
- `views/operation-card.php` — محتوى بطاقة التشغيل.
- `views/license.php` — محتوى الترخيص.
- `../templates/layout.php` — القالب المشترك (الهيدر/الفوتر/الستايل بالكامل كما هو).

الرابط القديم `/logisti/validate-driver-card?token=...` يعمل ويحوّل (301) للرابط الجديد.

## قاعدة البيانات

البيانات الجديدة ثابتة حاليًا ولا تحتاج أي تعديل على قاعدة البيانات.
لو حبيت تنقلها للداتابيز لاحقًا، أكواد MySQL جاهزة في `../sql/roles-tables.sql`.
