# naql — الرابط الموحّد للبطاقات والتراخيص

الرابط:

```
http://localhost/logisti/naql/validate-driver-card?token=XXXX
```

التوكن هو اللي يحدد الصفحة اللي تُعرض، وكل البيانات **ديناميك من قاعدة البيانات**:

| النوع (Role)              | الجدول            | العنوان الأخضر أعلى الصفحة |
|---------------------------|-------------------|-----------------------------|
| بطاقة سائق (Driver Card)  | `driver_cards`    | تفاصيل بطاقة السائق         |
| بطاقة تشغيل (Operation)   | `operation_cards` | تفاصيل بطاقة التشغيل        |
| ترخيص (License)           | `licenses`        | قيمة العمود `activity`      |

الراوتر بيدوّر على التوكن في الجداول الثلاثة بالترتيب.

**أي حالة خطأ** (توكن فاضي / توكن غير موجود / فشل الاتصال بقاعدة البيانات) →
تحويل صامت (302) للموقع الرسمي من غير ما يظهر أي رسالة خطأ للزائر:

```
https://logisti.sa/naql/validate-license?token=<نفس التوكن>
```

## إعدادات قاعدة البيانات

`config/database.php` بيختار الإعدادات تلقائيًا حسب الدومين:
`localhost` → إعدادات الجهاز، وأي دومين تاني (logisti.gt.tc) → إعدادات InfinityFree،
وتقدر تتغلب عليهم بمتغيرات البيئة `DB_HOST` / `DB_NAME` / `DB_USER` / `DB_PASS`.

## الملفات

- `validate-driver-card.php` — الراوتر (يحدد النوع من التوكن ويجيب الصف من الجدول المناسب).
- `views/driver-card.php` — محتوى بطاقة السائق.
- `views/operation-card.php` — محتوى بطاقة التشغيل.
- `views/license.php` — محتوى الترخيص.
- `../templates/layout.php` — القالب المشترك (الهيدر/الفوتر/الستايل بالكامل كما هو).

الرابط القديم `/logisti/validate-driver-card?token=...` يعمل ويحوّل (301) للرابط الجديد.

## قاعدة البيانات

كل أكواد MySQL في `../sql/roles-tables.sql`:

- `operation_cards` و `licenses` (اتعملوا بالفعل).
- أعمدة اختيارية على `driver_cards` (`entity_name`, `entity_id`, `license_number`,
  `license_type`, `city`, `license_issue_date`, `license_expiry_date`) عشان بيانات
  المنشأة/الترخيص في صفحة السائق تبقى ديناميك كمان. لو الأعمدة دي مش موجودة أو فاضية،
  الصفحة بتستخدم القيم الافتراضية القديمة تلقائيًا.

## الإضافة من لوحة التحكم

`/logisti/admin/` → اختار النوع (بطاقة سائق / بطاقة تشغيل / ترخيص) → املأ الحقول →
هيتولّد توكن تلقائيًا ويطلعلك الرابط + QR.
